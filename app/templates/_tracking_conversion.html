{# Ad-conversion snippet for the thank-you page. Rendered per platform ONLY while the server has confirmed this is a genuine public enquiry that has not yet had that platform's conversion dispatched by a browser (see app.api.enquiries.enquiry_thanks -> emit_ga4 / emit_meta). Rendering the page does NOT mark the conversion emitted. Each block fires its tag, and ONLY if the tag was actually present and fired does it (a) set a per-platform localStorage key (same-browser refresh guard) and (b) beacon the server to record the dispatch (cross-browser / durable guard). So a blocked or not-yet-loaded tag marks nothing and can still fire on a later load -- a real conversion is never permanently suppressed just because the page rendered -- while a refresh / Back-Forward after a confirmed dispatch re-checks both guards and does not re-fire. Platforms are independent: GA4 blocked while Meta succeeds (or vice versa) leaves the other's flag NULL, so it fires on its own next chance. Non-PII only: lead_id is the reference_code (event date + random suffix); no name, email, phone or free text is ever sent. #}
